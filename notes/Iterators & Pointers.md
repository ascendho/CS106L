# Iterators & Pointers

## 一、容器小测验（核心答案）
1. **支持前后插入效率均等的容器**：`std::deque`（双端队列）。
2. **需要元素类型支持比较运算符的容器**：`std::map`（有序映射）、`std::set`（有序集合）。
3. **更快的容器：`std::unordered_set` vs `std::set`**：`std::unordered_set` 更快，原因是基于哈希表实现+低负载因子，查询/插入复杂度为 O(1)（平均情况）；而 `std::set` 基于红黑树，复杂度为 O(log n)。
4. **规避比较运算符要求的方案**：使用无序容器（如 `std::unordered_map`、`std::unordered_set`），依赖哈希函数而非比较运算。

## 二、范围 for 循环的底层原理
范围 for 循环 `for (const auto& elem : container)` 并非语法糖，而是编译器自动转化为**迭代器遍历**，等价于：
```cpp
auto b = container.begin();  // 迭代器指向容器首个元素
auto e = container.end();    // 迭代器指向容器末尾的「后一位」（不指向实际元素）
for (auto it = b; it != e; ++it) {
    auto elem = *it;         // 解引用迭代器获取元素
    // 循环体逻辑
}
```
该机制适用于所有 STL 容器（`vector`、`deque`、`map`、`set` 等），本质是迭代器提供了统一的遍历接口。

## 三、迭代器基础
### 1. 迭代器的核心定位
迭代器是连接容器与遍历操作的「桥梁」，类比「抓娃娃机的爪子」，核心功能：
- 抓取元素（解引用 `*it`）；
- 向前移动（递增 `++it`）；
- 判断是否结束（与 `end()` 比较 `it == c.end()`）。

容器需提供的关键接口：
- `container.begin()`：返回指向**首个元素**的迭代器（容器非空时）；
- `container.end()`：返回「尾后迭代器」（指向容器最后一个元素的下一位，永远不指向实际元素）；
  - 空容器的 `begin()` 与 `end()` 相等。

### 2. 迭代器的核心操作接口
| 操作                | 功能描述                                  | 注意事项                          |
|---------------------|-------------------------------------------|-----------------------------------|
| `auto it = c.begin()` | 拷贝构造（获取迭代器）                    | -                                 |
| `++it`              | 向前递增迭代器（移动到下一个元素）        | 优先使用前缀形式（`++it`）而非 `it++` |
| `*it`               | 解引用迭代器，获取指向的元素              | 禁止对 `end()` 迭代器解引用        |
| `it == c.end()`     | 判断迭代器是否到达容器末尾                | 用 `!=` 而非 ` < ` 比较（适配所有容器） |
| `it->member`        | 访问元素的成员（等价于 `(*it).member`）   | 适用于元素为结构体/类的场景        |

### 3. 前缀递增（`++it`）vs 后缀递增（`it++`）
- 前缀形式（`++it`）：直接递增迭代器，返回**自身引用**，无额外拷贝，效率更高；
- 后缀形式（`it++`）：递增迭代器后，返回**原状态的拷贝**，产生不必要的开销（迭代器是对象，拷贝成本高于int）。
- 建议：遍历容器时优先使用 `++it`（Bjarne Stroustrup 推荐）。

## 四、迭代器类型（按功能分级）
迭代器按支持的操作分为 5 类，功能从基础到高级递增，不同容器的迭代器属于不同类型：

### 1. 输入迭代器（Input Iterator）
- 最基础类型，仅支持「只读+单遍遍历」；
- 核心操作：`*it`（读元素）、`++it`（向前移动）；
- 示例：`std::istream_iterator`（从标准输入读取数据）：
  ```cpp
  std::istream_iterator<int> start(std::cin);  // 从cin读取int
  std::istream_iterator<int> end;              // 尾后标记（Ctrl+D触发）
  std::vector<int> nums(start, end);           // 读取所有输入到vector
  ```

### 2. 输出迭代器（Output Iterator）
- 仅支持「只写+单遍遍历」；
- 核心操作：`*it = elem`（写元素）、`++it`（向前移动）；
- 示例：`std::back_insert_iterator`（向容器尾部插入元素）：
  ```cpp
  std::vector<int> v;
  std::back_insert_iterator<std::vector<int>> out_it(v);
  *out_it = 10;  // 等价于 v.push_back(10)
  *out_it = 20;  // 等价于 v.push_back(20)
  ```

### 3. 前向迭代器（Forward Iterator）
- 继承输入迭代器的功能，支持「多遍遍历」（可重复访问元素）；
- 所有 STL 容器的迭代器至少是前向迭代器；
- 核心特性：满足「多遍保证」—— 若 `it1 == it2`，则 `++it1 == ++it2`。

### 4. 双向迭代器（Bidirectional Iterator）
- 继承前向迭代器的功能，支持「向前+向后移动」；
- 新增操作：`--it`（向前移动一位）；
- 适用容器：`std::map`、`std::set`、`std::unordered_map`、`std::unordered_set`；
- 示例（访问 `map` 最后一个元素）：
  ```cpp
  std::map<int, int> m{{1,2}, {3,4}};
  auto it = m.end();
  --it;  // 移动到最后一个元素（{3,4}）
  std::cout << it->first << " " << it->second;  // 输出 3 4
  ```

### 5. 随机访问迭代器（Random Access Iterator）
- 最高级类型，支持「跳跃式移动+随机访问」；
- 新增操作：`it += n`（跳跃n步）、`it -= n`（反向跳跃n步）、`it[n]`（访问第n个元素）、`it1 < it2`（比较位置）；
- 适用容器：`std::vector`、`std::deque`（连续内存或伪连续内存容器）；
- 示例（vector 随机访问）：
  ```cpp
  std::vector<int> v{1,2,3,4,5};
  auto it = v.begin();
  it += 2;  // 跳跃到第3个元素（值为3）
  std::cout << it[0];  // 等价于 *it，输出3
  std::cout << it[1];  // 访问下一个元素，输出4
  ```

### 迭代器类型总结表
| 类型               | 核心能力                          | 支持的容器/示例                  |
|--------------------|-----------------------------------|---------------------------------|
| 输入迭代器         | 只读、单遍                        | `std::istream_iterator`         |
| 输出迭代器         | 只写、单遍                        | `std::back_insert_iterator`     |
| 前向迭代器         | 只读/写、多遍                     | 所有 STL 容器（基础类型）        |
| 双向迭代器         | 前后移动、多遍                    | `map`、`set`、`unordered_map`   |
| 随机访问迭代器     | 跳跃移动、随机访问、多遍          | `vector`、`deque`                |

### 为什么需要分类型？
- 统一抽象：所有迭代器共享基础接口（`++it`、`*it`），实现「跨容器统一遍历」；
- 效率适配：容器的底层实现决定迭代器能力（如 `vector` 是连续内存，支持随机访问；`map` 是红黑树，仅支持双向移动），避免提供低效操作（如 `map` 不支持 `it += 5`，因跳跃需遍历树，效率极低）。

## 五、指针与内存
### 1. 内存基础
- 内存是「字节寻址」的存储区域，每个字节有唯一地址（64位系统地址范围：0x0 ~ 0xFFFFFFFFFFFFFFFF）；
- 变量的地址 = 其占用内存的「最低字节地址」（如 int 占4字节，地址为首个字节的编号）；
- 内存分区（简化）：全局变量区、栈（局部变量）、堆（动态分配）、代码区（指令）。

### 2. 指针的核心概念
- 指针是「变量的内存地址」，本质是一个整数（存储地址值）；
- 语法：
  - `&变量`：获取变量的地址（取地址符）；
  - `*指针`：解引用指针，获取指向的变量（解引用符）；
  - `指针->成员`：访问指向对象的成员（等价于 `(*指针).成员`）。
- 示例：
  ```cpp
  int x = 106;
  int* px = &x;  // px 存储 x 的地址（如 0x50527c）
  std::cout << *px;  // 解引用，输出 106
  std::cout << px;   // 输出地址（如 0x50527c）
  ```

### 3. 指针与迭代器的关系
- 接口相似：指针支持 `++`（移动）、`*`（解引用）、`==`（比较）、`+=n`（随机访问），与随机访问迭代器的接口完全一致；
- 底层关联：`std::vector` 的迭代器底层可视为「包装后的指针」（实际 STL 实现更复杂，但逻辑等价于 `T*`）；
- 示例（vector 指针与迭代器功能一致）：
  ```cpp
  std::vector<int> v{1,2,3,4,5};
  // 指针遍历
  int* ptr = &v[0];
  ptr += 2;  // 跳跃到第3个元素
  std::cout << *ptr;  // 输出3
  // 迭代器遍历（功能完全一致）
  auto it = v.begin();
  it += 2;
  std::cout << *it;  // 输出3
  ```

## 六、核心总结

1. **迭代器**：容器的「遍历接口」，统一不同容器的遍历逻辑，核心操作是 `++it`（移动）、`*it`（访问元素）、`it == end()`（判断结束）；
2. **迭代器类型**：从基础到高级分为输入、输出、前向、双向、随机访问，容器的底层实现决定迭代器能力；
3. **指针**：变量的内存地址，与迭代器接口同源，`vector` 迭代器的功能与指针高度一致；
4. **关键细节**：优先使用 `++it` 而非 `it++`；`end()` 不指向实际元素，禁止解引用；
5. **后续内容**：下节课将通过类（Class）实现自定义容器的迭代器（如 `map` 的迭代器）。
